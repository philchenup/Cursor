# T 型板焊缝定位

俯视点云里没有立板回波，黑色缝是坡口。焊缝不从黑色像素里抽，而从两侧板件的棱边求：

- **两侧焊趾**：两块板相向的棱边
- **中间焊缝**：两条焊趾的中线

端点取两块板沿缝方向的重叠段，也就是真正搭接、需要焊接的那一段。坡口两端多出来的尖角是超出板端的空缺，不拿来当焊缝长度。黄板上的小黑洞在板内部，不会被当成焊缝。

坐标是像素，原点在左上角，x 向右，y 向下。图上没有标定，不能直接当成机器人基坐标。

## 为什么这样更稳

骨架化或直接找黑色连通域会把飞溅、板内孔洞、和背景连在一起的坡口都算进去。板件棱边是实体边界：

1. 四角同色的无回波区域视为背景。
2. 前景的颜色中值是底板。与底板的 Lab 距离做 Otsu，剩下的细长连通域是板件。底板必须占前景 40% 以上，否则直接拒绝，避免主色判错。
3. 只配对长边夹角小于 15°、沿法向相对、缝宽小于较窄那块板、并且重叠够长的两块板。首尾相接或离得很远的平行板配不上。
4. 沿焊缝分箱，相向棱边取 99.5 分位，躲开个别飞出的点。缝宽取中位数，偏离过大的箱子用 MAD 丢掉。
5. 中间焊缝是两条焊趾的平均，端点是两块板 1% 截尾后的重叠区间。

闭运算核默认 11 px，必须小于坡口宽度，否则两块板会粘成一块。

## 立板有点时

`tjoint_seams_3d` 用固定种子的 RANSAC 抽翼板，把高出翼板的点投影下去，再对投影带做同一套边缘包络。两面点云疏密不同时，中心线仍在两条边缘中间。只扫到一面时，得到的是这一面的焊趾，另一侧按已知板厚偏置。
